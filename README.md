# company-site

- This project is a website developed with HTML, CSS and Bootstrap. Its aim is to create a platform that encourages knowledge sharing, supports team promotion and content presentation.

# Preview

  ![](/paylaştıkça.gif)

# Project Content

- - Home Page: General information about the project and the welcome screen.

- - About Us: The section that explains the purpose and vision of the platform.

- - Our Team: A page where team members are introduced with their photos and titles.

- - Gallery: The section where visual sharing takes place.

- - Communication: The area where users can communicate with the platform.

# Properties

- - Ability to switch between sections using the menu

- - Drop down menu

- - Modern and sleek design

- - Mobile, tablet, and desktop compatibility

- - Optimized code structure
